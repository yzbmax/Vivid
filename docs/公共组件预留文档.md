## 一、文档目的与组件边界

### 1.1 为什么需要"预留"

当前工程仅有脚手架（`pages/Index.ets` 为空壳），尚未实现任何页面。页面并行开发时最容易出现的问题，是**同一个控件在各页面各写一套**（比如每个页面都自建一个"红色主按钮"），导致：

- 样式漂移（色值、字号、按压反馈不一致）；
- 后期改一个控件要改 N 处；
- 无法复用已设计好的交互与动效。

因此本清单在页面实现**之前**，先锁定公共组件的**接口契约**（命名、路径、入参、事件、样式令牌、复用点），实现时按此建设，页面按此引用。

### 1.2 "公共组件"的定义与分类

| 类别 | 定义 | 判定标准 |
|---|---|---|
| **框架组件** | 全局骨架，每个页面都有 | 被 2 个及以上一级页面复用 |
| **基础控件** | 单一交互原语（按钮、滑块、标签…） | 被 2 个及以上页面复用，或虽是编辑页专属但属于可复用领域控件 |
| **领域组件** | 绑定某个业务对象（作品、编辑状态…） | 被 2 个及以上页面复用，或承担明确领域职责 |
| **组合组件** | 由多个基础控件组装而成 | 在一个页面内承担完整区块职责 |
| **预留装饰** | 设计语言已确认、但对应功能不在 V1 范围 | stitch 样板已出现，作为未来功能的组件契约预留 |

### 1.3 组件与页面/服务的边界（分层约定）

```
pages/（页面：组合编排 + 持有业务状态）
   │ 回调向上抛事件（onSelect / onAdjust / onSave…）
   ▼
components/（组件：呈现 + 交互反馈，无业务逻辑）
   │
   └── 不 import services/ stores/，不持有全局状态
```

硬性约定：

1. **组件不直接调用 `services/*` 与 `stores/*`**。图片选择、AI 分割、渲染、保存一律由页面调用服务后，把结果以参数注入组件或由组件回调抛出。
2. **状态单向流入**：页面持有状态，通过 `@Prop`（单向）/ `@Link`（双向）注入组件；组件内部 `@State` 只保存纯 UI 状态（展开/收起、选中项、动画开关）。
3. **事件向上抛出**：组件只负责把"用户想做什么"抛给页面，具体副作用（写 Store、调服务、路由）由页面处理。
4. **令牌唯一来源**：颜色/字体/间距/动效一律取 §三 令牌表，禁止在组件内写令牌之外的色值/字号。

命名规范：

- 组件一律 `@Component export struct XxxYyy`（大驼峰），文件名与 struct 同名；

- 布尔入参一律 `xxx?: boolean = false` 的形式给出默认值。

### 1.5 与《项目结构》/PRD 的关系

- 本清单**完整继承**《项目结构》已列的组件名（`MainTabBar`、`ImportCard`、`WorkGrid`、`WorkCard`、`SettingsList`、`PreviewArea`、`RegionTabs`、`AdjustPanel`、`AdjustSlider`、`MaskOverlay`、`ActionBar`），不修改其命名，只补齐接口契约；
- `AdjustSlider` 按《项目结构》保持位于 `editor/`（不因未来复用而提前挪动）；当印信/水印等未来功能确实复用它时，再将其提升至 `common/` 并在《项目结构》中同步；
- `common/`、`home/RecentWorkRail`、`editor/CompareChip` 等为本清单**新增**的公共控件，已按 PRD §8.2（分层与代码目录映射）与《项目结构》§五（建议代码目录）的挂载位置归位；后续若更新《项目结构》，以本文档的 `components/` 树为准增补；
- **命名对齐**：《项目结构》页面树中的作品页"空状态 EmptyWorks"节点，由本清单 `EmptyState` 组件呈现（见 B8），实现时两个名字指向同一组件，避免并存。

### 3.4 动效令牌

| 令牌 | 关键帧 | 用途 |
|---|---|---|
| `stamp-in`（盖章） | `opacity 0→1; scale 1.5→0.9→1; rotate 5deg→0`，0.6s `cubic-bezier(.175,.885,.32,1.275)` | 成功图标、印章落下（FeedbackMessage、SealBadge 入场） |
| `fade-up`（浮上） | `opacity→1; translateY(0)`，0.5s ease-out | 文案/按钮错峰入场（FeedbackMessage） |
| `unfold-scroll`（卷轴展开） | `opacity 0; scaleY(0)→1`，0.8s `cubic-bezier(.2,0,0,1)`，`transform-origin: top center` | 归档作品卷轴展开（PaperFrame、保存成功） |
| `press-seal`（按压） | `scale 0.98`，~0.15s | 所有按钮按下的"盖章"反馈 |
| `slider-zoom` | 滑块头 `scale 1.1` | AdjustSlider 拖动中 |
| `tab-slide` | 指示条 `scaleX` 过渡 0.3s | SegmentTabs / RegionTabs |
| `button-sheen` | 斜向高光扫过 0.7s | 关键主按钮（落印保存） |

> ArkUI 迁移：用 `animateTo` / `transition` / `keyframeAnimateTo` 复刻，stamp-in→scale+rotate，unfold-scroll→scaleY，压按→`scale(0.98)`。

### 3.5 令牌落地建议

1. 颜色：写入 `resources/base/element/color.json`（新增令牌名），组件用 `$r('app.color.xxx')` 引用；同时维护 `resources/dark/element/color.json` 深色覆盖（脚手架已具备该结构）。
2. 字体/间距/动效：在 `components/common/Theme.ets` 导出常量（如 `const GRID_UNIT: Length = '5.4rem'`、`const FONT_LABEL_MONO: ...`），组件 `import { Theme } from '../common/Theme'` 使用。
3. 禁止在单个组件内硬编码令牌外的值；确需微调间距，取 `Theme` 常量的倍数（如 `Theme.GRID * 2`）。

## 四、组件预留规格

> 统一规格字段：**用途 / 复用场景 / 交互与状态 / 入参（Props）/ 事件（Events）/ 样式令牌 / 动效 / 无障碍 / 预留扩展点 / 参考屏**。
> ArkTS 签名为"预留契约"——页面按此入参调用，组件实现按此签名，避免联调时改接口。

#### B1. AppButton —— 按钮（主 / 次 / ghost）

- **用途**：全应用统一按钮；钤印按压反馈（`scale 0.98`）。文案用**动词化卷宗语**（呈验 / 落印 / 落印保存 / 返回主阁 / 分发令 / 执行置换 / 启封续编）。
- **复用场景**：首页导入、编辑页保存/对比、设置页、空状态引导、成功反馈页。
- **交互与状态**：
  - `type: 'primary' | 'inverse' | 'ghost' | 'text'`
    - `primary`：`bg-primary` 白字，hover/按压 `seal-red`，可叠"白闪"覆盖层；
    - `inverse`：`bg-inverse-surface`（深色，Seal Lab"落印"）`inverse-on-surface` 文字；
    - `ghost`：透明底 + `text-primary` + `border primary/20`，hover `bg-primary/5`；
    - `text`：纯文字链接（全部查看 / 遗失密钥）；
  - `disabled`：降透明 + 禁止点击；
  - `loading`：显示 LoadingIndicator（见 E2）。
- **入参**：

  ```typescript
  @Component
  export struct AppButton {
    type: 'primary' | 'inverse' | 'ghost' | 'text' = 'primary';
    label: string = '';
    icon?: string = '';           // 图标语义名
    disabled: boolean = false;
    loading: boolean = false;
    fullWidth: boolean = true;
    height?: Length = '3.5rem';   // 主力按钮 py-4 ≈ 56dp
    costNote?: string = '';       // 按钮下方成本/说明小字（_1「扣除1点印信积分」）
    onClick: () => void = () => {};
  }
  ```

- **事件**：`onClick`。
- **样式令牌**：`primary`/`seal-red`/`inverse-surface`/`outline-variant`；文字 `body-md`（大字按钮 18fp）/ `label-mono`（ghost 按钮 uppercase）；`costNote` 用 `label-mono` 10px。
- **动效**：`press-seal`（scale 0.98）、主按钮 `button-sheen`。
- **无障碍**：触控区 ≥48dp；`label` 作为语义内容。
- **预留扩展点**：未来新增"危险操作"类型（删除，用 `error`）；支持 `leftIcon`/`rightIcon` 细分。
- **参考屏**：_1（执行置换）、_2（呈验）、_4（返回主阁/分发令）、_5（落印保存）、_6（hero）、Work Detail（启封续编）。

#### B2. SegmentTabs —— 通用分段切换

- **用途**：一段等宽分段，激活项带语义指示。
- **复用场景**：作品页筛选（全部卷宗/已封印/草稿）、编辑页主体/背景（由 RegionTabs 语义封装）、未来字号 S/M/L、印信底色等。
- **交互与状态**：
  - `items` 由入参驱动；


- **事件**：`onChange(key)`。
- **样式令牌**：激活 `on-surface` + `seal-red` 指示条；未激活 `on-surface-variant/50`；角标 `on-primary-fixed-variant`。
- **动效**：`tab-slide`（指示条 scaleX 0.3s）。
- **无障碍**：`accessibilitySelected`；指示条不拦截点击。
- **预留扩展点**：未来支持图标段、滚动式分段（作品页三标签横向滚动）。
- **参考屏**：_5（主体/背景）、Works Page（全部卷宗/已封印/草稿）、_3（S/M/L）。

#### B3. AdjustSlider —— 调色滑块（核心控件）

- **用途**：编辑页四个调色参数（亮度/对比度/饱和度/色温）的滑块；也是未来印信/水印参数的滑块基座。
- **复用场景**：编辑页 `AdjustPanel` 内四条；未来 `SealPicker`/`Seal Lab`（留白、字号）。
- **交互与状态**：
  - 轨道：基线 1px `outline-variant` + 填充 2px `seal-red`，宽度 = 数值百分比；
  - 滑块头：**朱砂方块** 16×16（`bg-seal-red`，内含 6×6 `bg-surface` 内芯，微印章感），拖动 `scale 1.1`；
  - 值标签：右侧右对齐，`label-mono` 加粗 `text-primary`，格式带符号两位（`+15 / +08 / -12 / +22`）；
  - `value ∈ [-100, 100]`，默认 0；拖动实时回调（节流见 PRD F4）。
- **入参**：

  ```typescript
  @Component
  export struct AdjustSlider {
    label: string = '';       // 亮度 / 对比度 / 饱和度 / 色温
    unit?: string = '';       // LUM / CON / SAT / TMP（等宽小字）
    value: number = 0;        // -100 ~ +100（@Prop，由 EditStore 注入）
    step: number = 1;
    onValueChange: (value: number) => void = () => {};
    onDraggingEnd?: () => void = () => {};   // 松开时触发（用于触发渲染/埋点）
  }
  ```

- **事件**：`onValueChange`（拖动中，节流后回调）、`onDraggingEnd`（松开）。
- **样式令牌**：`seal-red` 填充/滑块头、`outline-variant` 基线、`on-surface`/`on-surface-variant` 标签、`primary` 值。
- **动效**：`slider-zoom`（拖动中滑块头放大）。
- **无障碍**：滑块可拖拽；值随动 `accessibilityText`（如"亮度，正 15"）；触控高度 ≥48dp。
- **预留扩展点**：未来蒙版羽化强度、更多参数（HSL）直接复用；支持 `showTicks`/`marker`。
- **参考屏**：_5（核心四条）、_3（留白滑块变体：石块形滑块头 `bg-inverse-surface border primary/20`）。

#### B4. InputField —— 输入框

- **用途**：带标签/图标的文本输入。
- **复用场景**：设置页（存储/行为配置）、未来登录页（_2 卷宗查验）、水印设备签（_3）。
- **交互与状态**：
  - `variant: 'card' | 'underline'`

- **入参**：

  ```typescript
  @Component
  export struct InputField {
    label: string = '';
    placeholder: string = '';
    value: string = '';
    icon?: string = '';              // 左侧图标
    variant: 'card' | 'underline' = 'card';
    secure: boolean = false;
    trailingAction?: string = '';    // 右侧图标（如 edit）
    onChange: (value: string) => void = () => {};
  }
  ```

- **事件**：`onChange`。
- **样式令牌**：`outline-variant`/`on-surface`/`paper-surface`；`label-mono` 标签、`body-md` 内容。
- **无障碍**：label 与输入关联；secure 切换钮有语义标签。
- **预留扩展点**：未来验证码/手机号格式校验（`validator` 入参）。
- **参考屏**：_2（卡片式）、_3（下划线式）。

## 六、组件树与数据流

### 6.1 EditPage（编辑页）组件树

```text
EditPage（页面：持有 EditStore 会话，调用分割/渲染/保存服务）
└── PaperBackground
    ├── TopBar（showBack + title 蒙版调色）
    ├── PreviewArea
    │   ├── CompareChip（按住对比 → onPressStart/End → 页面切原图/效果图）
    │   └── MaskOverlay（蒙版查看 → visible）
    ├── RegionTabs（主体/背景 → EditStore.region）
    ├── AdjustPanel
    │   ├── AdjustSlider（亮度 [LUM]）
    │   ├── AdjustSlider（对比度 [CON]）
    │   ├── AdjustSlider（饱和度 [SAT]）
    │   └── AdjustSlider（色温 [TMP]）
    └── ActionBar（蒙版切换 / 重置 / 落印保存）
```

数据流示例（滑动亮度）：

```text
用户拖动 AdjustSlider
  → onValueChange(+15)
  → EditPage 更新 EditStore.subject.brightness
  → 节流 + 生成 PreviewRenderTask（ImageRenderService，预览尺寸）
  → onRenderComplete → @State previewImage 更新
  → @Prop 下发回 AdjustSlider.value 与 PreviewArea.image
```

### 6.2 Index（MainTabs 容器）组件树

```text
Index.ets（@Entry 主框架）
├── HomePage（Tab0）→ ImportCard / RecentWorkRail / StatTile
├── WorksPage（Tab1）→ SegmentTabs / WorkGrid / WorkCard / EmptyState
├── MinePage（Tab2）→ SettingsList
└── MainTabBar（currentIndex + onChange）
```

## 七、落地优先级与建设顺序

> 对齐 PRD 版本规划（Phase 1-4）。每阶段开始前，先建设本阶段的公共组件，页面再按 §五 映射组装。

| 阶段 | 需就绪的公共组件 | 页面交付 |
|---|---|---|
| **Phase 1（MVP，第 1-2 周）** | PaperBackground、TopBar、MainTabBar、FooterSealBar、AppButton、SegmentTabs、AdjustSlider、AdjustPanel、RegionTabs、ActionBar、PreviewArea、ImportCard、WorkCard、WorkGrid、StatusTag、SealBadge（装饰态）、EmptyState、LoadingIndicator、ErrorBanner | 首页导入 → 独立编辑页 → 分割 → 亮度/对比度 → 保存 → 作品页可见可再编辑 |
| **Phase 2（核心体验，第 3-4 周）** | SectionHeader、BottomPanel、StatTile、RecentWorkRail、MiniWorkCard、CompareChip、MaskOverlay、SettingsList、FeedbackMessage | 饱和度/色温、实时预览、对比、蒙版查看、重置、作品页完整体验、首页近期归档、我的/协议入口 |
| **Phase 3（稳定性，第 5 周）** | 不新增公共组件；性能/内存/节流/任务取消/崩溃修复 | 多机型稳定、隐私检查 |
| **Phase 4（上架，第 6 周）** | 不新增公共组件 | 图标/截图/隐私/上架材料 |
| **未来版本** | SealBadge（功能化）、SealPicker、ColorSwatchPicker、WatermarkBar、PaperFrame、NotesCard、MetadataBar、InputField、AccountBadge | 印信、水印钤印、作品详情、登录（按 PRD §5.2/§5.3 另行评估） |

> 依赖说明：`SegmentTabs` 因被 `RegionTabs`（Phase 1）封装而前移至 Phase 1；`StatusTag`/`SealBadge` 因被 `WorkCard`（Phase 1 作品页）引用而前移（装饰态）；`FooterSealBar` 因出现在全部主屏落款而前移。若时间紧张，Phase 1 可先在 `RegionTabs`/`WorkCard` 内联实现，Phase 2 再抽公共组件。
