> 文档版本：V1.0

## 〇、冒烟路径（优先跑通）

```
启动 App
  → 进入「作品」Tab
  → 看到 6 张作品卡
  → 点任意卡 → 进入详情页（标题/图片/编号正确）
  → 点「返 回 卷 宗 库」→ 回到列表（筛选/排序状态保留）
  → 无崩溃、无花屏、顶部不被状态栏遮挡
```

## 七、异常与边界

- [ ] 坏 workId（如改代码传 `'not-exist'`）→ 显示「卷宗详情」占位、无图片，不崩溃
- [ ] 作品预览图资源缺失 → 显示「无预览」占位，不崩溃
- [ ] toast 调用失败不影响页面（prompt 不可用时静默）

- [ ] 深色模式/跟随系统切换后，窗口背景与页面背景无突兀色块（当前 `#DEDDD7`）
