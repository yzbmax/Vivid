# Vivid 前端测试清单

> 适用阶段：当前前端功能基本完成、以模拟器为主进行测试。
> 使用方法：每项测试完成后，将 `- [ ]` 改为 `- [x]`。如发现问题，在“备注”中记录现象和复现步骤。

## 1. 基础功能

- [x] **F-01 App 启动**
  - 操作：完全关闭 App 后重新启动。
  - 通过标准：正常进入启动页面，无崩溃、无明显白屏、无异常布局跳动。
  - 备注：

- [x] **F-02 所有页面进入**
  - 操作：依次进入“我的”、登录、注册、用户设置、应用设置、用户协议、隐私政策。
  - 通过标准：所有页面均能正常显示，无空白页、缺失内容或明显错位。
  - 备注：

- [x] **F-03 页面返回**
  - 操作：从每个子页面使用返回按钮返回。
  - 通过标准：每次都返回正确的上一页，不出现跳错页面或直接退出 App。
  - 备注：

- [x] **F-04 快速重复点击入口**
  - 操作：快速双击或连续点击登录、注册、设置、协议等页面入口。
  - 通过标准：同一页面不会被重复压入导航栈。
  - 备注：

- [x] **F-05 登录模式切换**
  - 操作：在“验证码登录 / 密码登录”之间连续切换。
  - 通过标准：对应输入字段正确显示；不存在错误字段残留或状态错乱。
  - 备注：

- [x] **F-06 密码显示 / 隐藏**
  - 操作：输入密码后连续切换显示、隐藏。
  - 通过标准：密码内容不丢失，光标和输入状态正常。
  - 备注：

- [x] **F-07 密码安全键盘**
  - 操作：在密码隐藏和显示状态之间切换并继续输入。
  - 通过标准：模拟器中至少确认输入逻辑正常；真实安全键盘行为留待真机补测。
  - 备注：

- [x] **F-08 手机号本地校验**
  - 操作：测试合法手机号、位数错误、非法号段、空值。
  - 通过标准：仅符合 `^1[3-9]\d{9}$` 的手机号通过。
  - 备注：

- [x] **F-09 验证码校验**
  - 操作：测试 5 位、6 位、7 位、字母、符号等输入。
  - 通过标准：仅 6 位数字验证码通过。
  - 备注：

- [x] **F-10 密码规则校验**
  - 操作：测试纯数字、纯字母、字母数字组合、长度不足和长度超限。
  - 通过标准：仅符合当前密码规则的输入通过。
  - 备注：**密码框在输入超长文本后溢出，已修复**

- [x] **F-11 注册协议校验**
  - 操作：不勾选协议直接提交，再勾选后提交。
  - 通过标准：未勾选时阻止提交；勾选后进入正常前端校验流程。
  - 备注：

- [x] **F-12 协议页面滚动**
  - 操作：完整滚动用户协议和隐私政策页面。
  - 通过标准：正文可完整滚动，无截断、重叠或滚动失效。
  - 备注：

- [x] **F-13 空输入**
  - 操作：登录和注册表单全部留空并提交。
  - 通过标准：对应错误文案正确显示，不遮挡输入框和按钮。
  - 备注：

- [x] **F-14 超长输入**
  - 操作：在手机号、验证码、密码、昵称等字段粘贴或输入超长文本。
  - 通过标准：页面不崩溃、不明显溢出，校验逻辑正常。
  - 备注：

- [x] **F-15 粘贴异常字符**
  - 操作：粘贴空格、中文、Emoji、特殊符号等异常内容。
  - 通过标准：页面保持稳定，输入和校验结果符合预期。
  - 备注：

- [x] **F-16 快速连续输入**
  - 操作：快速连续输入并删除手机号、验证码和密码。
  - 通过标准：无明显掉字、卡死、输入错位或状态异常。
  - 备注：
