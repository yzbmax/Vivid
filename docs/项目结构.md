**V1 · 首发页面树：**

```text
蒙版调色 App（entry）
│
├─【V1 · 首发页面】
│
├── 首页 Index ──────────────────  pages/Index.ets
│   ├── 主动作：从相册选择（拉起系统相册选择器）
│   └── 说明文案：AI 自动识别主体 · 主体/背景独立调色 · 本地处理

├── 编辑页 EditPage ──────────────  pages/EditPage.ets
│   ├── 预览区 PreviewArea
│   │   ├── 长按 / 点击 → 原图对比（F5）
│   │   └── 蒙版查看叠加 MaskOverlay（F7 · P2）
│   ├── 区域切换 RegionTabs（F3.2）── 主体 / 背景

│   │   ├── 亮度滑块

│   │   ├── 饱和度滑块
│   │   └── 色温滑块
│   ├── 操作条 ActionBar
│   │   ├── 重置（当前区域 / 全部重置）
│   │   ├── 对比
│   │   └── 保存
│   └── 状态 / 异常反馈（弹层）
│       ├── AI 分割中 / 成功 / 失败

│       └── 异常提示 → 重试 / 返回
│
├── 系统能力（非页面，供页面调用）
│   ├── 相册选择器 PhotoViewPicker
│   └── 相册写入 PhotoAccessHelper
```
