# 蒙版调色项目结构

> 本文描述目标产品结构。当前主布局固定为「首页 / 作品 / 我的」，图片编辑使用独立页面承载，不作为底部导航项。

## 一、信息架构原则

1. 「首页 / 作品 / 我的」是应用的三个一级入口，使用底部导航切换。
2. 首页原有功能保持不变，仍以“从相册选择图片”为唯一主动作。
3. 从首页完成图片导入后，打开独立的编辑页，不在首页内直接编辑。
4. 作品页展示用户已保存的作品；点击作品图片后，打开同一个独立编辑页继续编辑。
5. 我的页只负责用户设置、应用设置和相关协议，不承载图片导入、图片编辑、作品展示或社区内容。
6. 编辑页不显示底部主导航，返回后回到发起编辑的一级页面。

## 三、核心页面流转

### 3.1 从首页新建作品

```text
首页
  ↓ 点击“从相册选择”
系统相册选择器
  ↓ 导入成功
编辑页（新建模式）
  ↓ AI 分割与图片编辑
保存
  ├── 导出到系统相册
  └── 新建本地作品记录
       ↓
作品页可见
```

### 3.2 从作品页继续编辑

```text
作品页
  ↓ 点击作品图片
编辑页（继续编辑模式）
  ↓ 恢复该作品的可编辑状态
继续调整
  ↓ 保存
更新本地作品记录并导出最新结果
```

### 3.3 返回规则

```text
首页进入编辑页  → 返回首页
作品页进入编辑页 → 返回作品页，并刷新作品展示
我的子页面      → 返回我的
```

## 四、作品数据结构

为了支持“保存后展示”和“点击后继续编辑”，作品不能只保存一张最终导出图，还需要保留恢复编辑状态所需的数据。

```text
WorkRecord
├── id                      作品唯一标识
├── sourceImageRef          源图片的应用内引用
├── previewImageRef         作品页缩略图引用
├── exportedImageRef        最近一次导出结果引用（如系统允许持久引用）
├── maskRef                 主体蒙版引用
├── subjectAdjustments      主体调色参数
├── backgroundAdjustments   背景调色参数
├── createdAt               创建时间
└── updatedAt               最近保存时间
```

约束：

- 本地作品数据只用于作品展示和继续编辑；
- 图片与编辑数据默认只在本地处理，不因作品功能自动上传；
- 新建模式首次保存时创建 `WorkRecord`；
- 继续编辑模式保存时更新原作品，不重复创建作品；
- 作品删除、批量管理、云同步和跨设备流转不属于本次结构范围。

## 六、页面职责边界

| 页面 | 负责 | 不负责 |
|---|---|---|
| 首页 | 原有图片导入入口与能力说明 | 图片编辑、作品管理、设置 |
| 作品 | 展示已保存作品、点击作品进入编辑 | 图片导入、用户设置、社区内容 |
| 我的 | 用户设置、应用设置、相关协议 | 图片导入、图片编辑、作品展示 |
| 编辑页 | AI 分割、主体/背景调色、预览、对比、重置、保存 | 一级导航、设置、作品列表 |

## 七、后续功能挂载点

以下能力不属于本次主布局，但后续可在不破坏当前页面职责的前提下扩展：

```text
编辑页内增强
├── 手动修正蒙版 / 手动画笔抠图
├── 蒙版羽化强度
├── 多主体选择 / 分别调色
├── 天空等语义级分区
├── 曲线 / HSL / 局部画笔
└── 一键预设

独立后续能力
├── 服务卡片（桌面 Widget）
├── 云端 AI
└── 跨设备流转
```

社区、模板、滤镜商城、登录、印信服务和水印钤印均不自动归入「我的」；如未来确认需要，应重新评估其产品入口与版本范围。
