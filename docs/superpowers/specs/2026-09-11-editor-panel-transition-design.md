# 底部编辑栏两档高度收敛与物理弹簧阻尼过渡设计规范 (Two-Tier Panel Height Transition Design)

## 1. 背景与核心问题
在 Vivid 的独立调色编辑页 (`EditPage.ets`) 中，底部编辑操作区目前包含 7 项核心工具：
`滤镜 (filter) | 主体 (subject) | 背景 (background) | 调节 (adjust) | 贴纸 (sticker) | 文字 (text) | 边框 (border)`。

原实现中各个面板高度各不相同（调节 110vp、滤镜 176vp、贴纸 170~210vp、边框 260vp、文字 300vp），且通过 `if-else` 条件直接挂载，导致：
1. 切换 Tab 时底栏高度大幅突变；
2. 由于中间预览区 `PreviewArea` 设置了 `.layoutWeight(1)`，底栏高度突增导致画芯瞬间被挤压变形、尺寸重绘，视觉剧烈晃动；
3. 面板内容瞬切无补间帧，观感生硬。

## 2. 解决方案设计：两档阶梯收敛 + 物理弹簧阻尼动画

### 2.1 两档标准高度体系
- **轻量调节档 (`EDITOR_PANEL_HEIGHT_COMPACT = 138`)**：
  - 适用工具：`adjust`（调节）、`filter`（滤镜）、`subject` 与 `background`（区域调节）。
  - 目标：将纵向 70%+ 的屏幕视野留给照片主画面，支持单手舒适微调。
  - 同档切换特性：高度保持 138vp，0 像素变动，画芯绝对静止。
- **综合配置档 (`EDITOR_PANEL_HEIGHT_EXTENDED = 248`)**：
  - 适用工具：`border`（装裱·边式）、`sticker`（贴纸）、`text`（文字题签）。
  - 目标：为多层级模版卡片、多组滑块、颜色盘、文字输入提供舒展的操控纵深。
  - 同档切换特性：高度保持 248vp，0 像素变动，画芯绝对静止。

### 2.2 动效设计
1. **外层容器弹簧动画**：
   - 使用 ArkUI 物理弹簧曲线：`curves.springMotion(0.35, 0.82)`。
   - 响应周期 350ms，阻尼比 0.82，在终点带有极微小细腻的物理回弹感，完全杜绝机械生硬感。
   - 支持多点触控与连续点击无缝物理打断（Interruptible）。
2. **容器防溢出**：
   - 动效外层容器开启 `.clip(true)`，确保高度收缩过程中不会发生子组件遮挡底栏或边缘外溢。
3. **内容交叉淡入淡出 (Crossfade)**：
   - 内部面板在工具切换时配合 150ms 的渐显渐隐与轻微纵向位移（+6vp -> 0vp），消除组件替换瞬间的视觉白闪。

## 3. 面板内部适配
- **AdjustPanel**：在 138vp 空间内适度增加上下边距，增强呼吸留白与触摸热区。
- **FilterPanel**：横向滤镜卡片 Scroll 调整为 84vp，卡片 56×56vp，浓度滑块 36vp，总高锁定在 138vp 内。
- **BorderPanel**：标题 (24) + 模版横滑 (72) + 4组滑块/色板 (138) + 间距 (14) = 248vp 完美容纳。
- **StickerPanel**：未选中与选中态统一占据 248vp，内部自适应居中，消除贴纸内部的二次高度晃动。
- **TextPanel**：固定高度 248vp，内部具备纵向滚动能力，确保不顶撞画芯。
