# Vivid 0.1.9 滤镜、文字与边框更新设计规格

**版本：** Vivid 0.1.9  
**日期：** 2026-09-01  
**代码基线：** `merge/all-three` / `c88e24a`  
**状态：** 已确认功能范围、总体架构与“模板”入口迁移规则

## 一、目标

Vivid 0.1.9 在现有调色、LUT 滤镜、贴纸、草稿和相册导出能力上增加三组离线编辑功能：

1. 新增 8 款内置 LUT 滤镜；
2. 增加可直接放置在照片上的文字图层，提供 5 款内置字体；
3. 增加 6 款可调节的照片边框模板，形成接近摄影边框应用的一键装裱体验。

所有新增效果必须同时进入实时预览、草稿恢复、作品续编、缩略图和正式导出链路，不允许出现“预览可见但导出丢失”或“续编后效果重置”。

## 二、范围冻结

### 2.1 新增滤镜

在现有 `FilterCatalog` 和原生 LUT 渲染链路上新增以下 8 款离线 `.cube` 预设：

| ID | 显示名 | 视觉目标 | 默认强度 |
|---|---|---|---:|
| `jade_mist` | 玉烟 | 低饱和青绿、柔和高光 | 0.68 |
| `cinnabar_glow` | 丹霞 | 暖红高光、轻微暖肤 | 0.65 |
| `ink_noir` | 墨影 | 冷调高反差黑白 | 0.80 |
| `rice_paper` | 宣纸 | 低对比、暖白、轻褪色 | 0.62 |
| `tea_film` | 茶褐 | 胶片褐色、压低蓝色 | 0.72 |
| `celadon_cool` | 青瓷 | 青蓝阴影、克制饱和度 | 0.70 |
| `amber_hour` | 琥珀 | 日落金黄、柔化阴影 | 0.66 |
| `moonlit_blue` | 月青 | 深蓝夜景、保留亮部 | 0.74 |

每个滤镜必须有唯一资源路径、稳定版本号、缩略图缓存键和独立强度。资源只允许随应用离线打包，不增加在线滤镜市场或下载逻辑。

### 2.2 文字图层

单张作品最多包含 8 个文字图层。每个图层支持：

- 1–80 个 Unicode 字符，最多 3 行；
- 新建、选中、重新编辑、拖动、删除；
- 字体、字号、颜色、位置、旋转和透明度；
- 字号范围为照片长边的 2%–20%；
- 旋转范围为 `-180°…180°`；
- 透明度范围为 `30%…100%`；
- 位置使用照片内容区域内的归一化中心坐标，不受预览尺寸和导出分辨率影响。

内置字体目录冻结如下：

| `fontKey` | 用户可见名称 | 来源与回退 |
|---|---|---|
| `system_sans` | 鸿蒙黑体 | 系统 `HarmonyOS Sans SC` |
| `noto_serif_sc` | 思源宋体 | `rawfile/fonts/notoserifsc.ttf`，失败时回退系统衬线 |
| `gkai` | 古籍楷体 | `rawfile/fonts/gkai.ttf`，失败时回退 `noto_serif_sc` |
| `system_mono` | 等宽题签 | 系统等宽字体，失败时回退 `system_sans` |
| `noto_serif_latin` | 西文衬线 | `rawfile/fonts/notoserif.ttf`，中文字符回退 `noto_serif_sc` |

颜色采用 8 个固定色板：墨黑、纸白、朱砂、深朱砂、青瓷、琥珀、灰墨、反色纸白。0.1.9 不提供任意取色器。

### 2.3 边框

边框是一个作品级状态，每张作品最多启用 1 款模板。模板目录冻结如下：

| `templateId` | 显示名 | 结构 |
|---|---|---|
| `none` | 无装裱 | 不改变输出画布 |
| `paper_white` | 宣纸留白 | 四边等宽浅色留白 |
| `ink_black` | 墨框 | 四边等宽深色留白 |
| `floating_shadow` | 浮光卡片 | 外画布、照片投影与轻微悬浮感 |
| `film_negative` | 胶片边框 | 深色边框、齿孔和底片编号装饰 |
| `polaroid` | 拍立得 | 左右上窄、底部加宽的白色相纸 |
| `scroll_mount` | 卷轴装裱 | 宣纸外框、细朱砂内线和角标 |

统一参数：

- `widthRatio`：`0…0.25`，按照片短边计算；
- `colorArgb`：从边框色板选择；
- `shadowStrength`：`0…1`；
- 模板不支持的参数在 UI 中禁用，而不是静默忽略；
- 边框只扩展画布，不裁剪照片；照片始终完整显示。

0.1.9 不新增第八个编辑工具，而是把现有占位工具 `template` / “模板”整体替换为 `border` / “边框”：

- `EditorToolKey`、`EDITOR_TOOL_KEYS`、`EDITOR_TOOLS` 和底部工具栏改用 `border`；
- 首页第 8 个快捷工具从“模板”改为“边框”，点击后直接打开编辑页边框面板；
- 历史路由、待处理编辑意图或旧作品中出现的 `template` 统一归一化为 `border`，不得打开空白占位面板；
- 贴纸模块内部的 `StickerTemplate` 是现有素材类型，不属于本次入口迁移，不改名、不重构；
- 不删除旧的 `home_Template.svg`；新增 `home_border.svg` 并切换引用，避免把文件删除或资源重命名混入本版本。

### 2.4 明确不做

- 在线滤镜、字体或边框市场；
- 用户导入字体、Logo、签名或第三方素材；
- EXIF 参数水印、相机品牌水印、自动字幕和多图拼接；
- 任意颜色取色器、渐变文字、描边文字、文字阴影和字距控制；
- 视频、Live Photo、RAW 或批量图片边框；
- 云同步、模板账号体系、付费模板；
- SDK、构建系统、状态管理方案或核心依赖升级；
- 重构现有贴纸系统，或把文字/边框伪装成贴纸实例。

## 三、架构

### 3.1 统一编辑快照

新建 `entry/src/main/ets/models/SharedContracts.ets`，由三人共同确认后冻结。跨模块数据只通过以下快照传递：

```typescript
export interface FilterSnapshot {
  filterId: string;
  strength: number;
}

export interface TextLayer {
  id: string;
  content: string;
  fontKey: string;
  colorArgb: number;
  fontSizeRatio: number;
  centerX: number;
  centerY: number;
  rotation: number;
  opacity: number;
  zIndex: number;
}

export interface BorderState {
  templateId: string;
  widthRatio: number;
  colorArgb: number;
  shadowStrength: number;
}

export interface EditorSnapshot {
  schemaVersion: number;
  filter: FilterSnapshot;
  textLayers: TextLayer[];
  border: BorderState;
}
```

`schemaVersion` 在 0.1.9 固定为 `1`。`WorkRecord.editorSnapshot` 为可选字段，旧作品缺失时使用原图滤镜、空文字数组和 `none` 边框，不做破坏性迁移。

所有写入快照的入口必须深拷贝数组和对象。任何非法数值在进入编辑会话时钳制；未知滤镜、字体或边框 ID 使用安全默认值，同时保留原作品记录，禁止因单个资源缺失导致页面崩溃。

### 3.2 渲染顺序

正式渲染顺序固定为：

```text
源图解码
  → LUT 滤镜
  → 现有全局/区域调色与蒙版
  → 在照片坐标系合成文字
  → 按边框模板扩展输出画布
  → 生成预览、缩略图或高清导出 PixelMap
```

文字先于边框合成，因此改变边框宽度不会移动文字相对照片的位置。边框不得反向改变滤镜、调色或文字参数。

### 3.3 预览与导出一致性

编辑拖动时采用混合预览：滤镜和调色继续由 `PreviewPipeline` 输出 PixelMap；文字与边框用 ArkUI 交互层即时显示。新增纯逻辑 `TextLayoutResolver` 和 `BorderLayoutResolver`，统一把归一化参数映射为预览坐标与导出像素坐标。

正式保存、作品缩略图和作品再次导出统一调用 `EditorCompositionService`，从源图和 `EditorSnapshot` 重新渲染，不截取页面 UI，不复用低分辨率预览 PixelMap。

一致性验收要求：

- 同一快照在预览和导出中的文字中心位置误差不超过预览坐标 2 px；
- 字号按照片长边等比缩放，比例误差不超过 1%；
- 边框输出尺寸、四边宽度和照片可见区域与模板规则一致；
- 草稿恢复和再次导出的快照字段逐项相同。

### 3.4 保存与恢复

`WorkSaveRequest` 增加 `editorSnapshot: EditorSnapshot`。`WorkSaveService` 在草稿和正式保存中都写入快照；正式保存还将快照交给 `EditorCompositionService` 生成最终 PixelMap。

`MockWorkStore.update()` 必须深拷贝 `editorSnapshot`。`WorkSaveService.exportWork()` 必须读取作品自身的快照，不允许只使用现有 `adjustments` 重新导出。编辑页续编时从 `WorkRecord.editorSnapshot` 恢复滤镜、文字和边框。

## 五、界面设计

### 5.1 工具栏与面板

- 继续使用现有编辑页，不新增独立页面；
- 现有“模板”工具直接替换为“边框”，工具总数仍为 7；
- “文字”工具用户可见标题为“题签”，入口文案为“添题签”；
- “边框”工具用户可见标题为“装裱”，模板选择文案为“边式”；
- 滤镜、题签、装裱使用同一底部面板高度和切换方式；
- 选中态使用 `seal-red #b23b2f`，主要动作使用 `primary #7b171b`；
- 滑块保持朱砂方块滑块头、1 px 弱轨道和 2 px 已选轨道；
- 标题使用衬线字体，参数标签使用等宽字体；
- 输入框采用浅纸白表面和下划线焦点态；
- 边框缩略图使用四角括号和浅朱砂内线，禁止引入新的视觉令牌。

### 5.2 文字交互

```text
进入“题签”
  → 点击“添题签”
  → 输入文字并确认
  → 新文字置于照片中心
  → 拖动调整位置
  → 面板调整字体/字号/颜色/旋转/透明度
  → 点击删除移除当前文字
```

键盘弹出时必须保证输入框和确认按钮可见。空字符串、全空白字符串不创建图层。达到 8 层后禁用“添题签”并显示“题签已满（上限 8 条）”。

### 5.3 边框交互

```text
进入“装裱”
  → 横向选择模板
  → 立即显示完整照片和边框
  → 调整留白、色纸和投影
  → 切换“无装裱”恢复原画布
```

边框参数变化只修改 `BorderState`，不得烘焙到当前预览源图。横图、竖图和长图都以完整显示照片为优先，不使用 `ImageFit.Cover` 裁切。

## 六、异常与回退

| 异常 | 处理 |
|---|---|
| LUT 文件缺失或解析失败 | 保留用户选择但显示加载失败；渲染回退原图，不覆盖已有作品 |
| 字体加载失败 | 按字体目录回退链显示和导出，并记录不含用户文字内容的错误日志 |
| 文字超出照片区域 | 保存状态时钳制中心点，保证至少 50% 文字包围盒位于照片内 |
| 边框资源缺失 | 当前模板回退 `paper_white`；若基础模板也失败则回退 `none` |
| 快照字段损坏 | 使用字段级默认值恢复；原记录保留，不自动重写 |
| 预览任务过期 | 沿用 generation token 丢弃旧结果并释放 PixelMap |
| 正式合成或编码失败 | 留在编辑页，允许重试或暂存草稿；不得显示已封缄 |
| 用户取消系统保存 | 删除本次单个缓存文件，作品保持草稿或原状态 |
| 内存不足 | 释放中间 PixelMap，显示“装裱生成失败”，不降低为 UI 截图导出 |

任何缓存清理只能删除一个明确文件路径，禁止递归或批量删除。

## 七、验证策略

### 7.1 单元测试

- 滤镜目录 ID、路径、默认强度、版本和缓存键；
- 文字内容、字号、位置、旋转、透明度钳制；
- 文字图层新增、选择、更新、删除、上限和深拷贝；
- 预览坐标与导出坐标换算；
- 边框参数钳制、模板能力和输出尺寸；
- `EditorSnapshot` 默认值、序列化、深拷贝和旧记录兼容；
- `MockWorkStore` create/update 后完整保留快照；
- 保存请求把同一快照传给草稿、正式保存和再次导出。

### 7.2 集成验证

- 每款新增 LUT 在同一测试图片上生成非空预览；
- 5 款字体分别覆盖中文、英文、数字和混合文本；
- 6 款边框覆盖横图、竖图、长图；
- 草稿保存、退出、恢复后逐项比对滤镜、文字和边框；
- 正式保存后从作品页再次导出，结果与第一次一致；
- 快速拖动文字、连续切换滤镜和边框时没有过期结果覆盖；
- 预览与导出位置、字号和边框尺寸达到一致性阈值。

### 7.3 项目级验证

该版本修改共享数据模型、预览、保存、作品恢复和导出链路，完成集成后必须运行相关单元测试、ArkTS 静态检查和一次 debug 构建。涉及系统相册、字体实际加载和高分辨率合成的结论必须在真机验证；没有真机时明确标记未验证，不以模拟器或静态检查替代。

## 八、完成定义

- 8 款新滤镜全部可选择、调强度、显示缩略图并导出；
- 单张照片可创建、编辑、移动和删除最多 8 个文字图层；
- 5 款字体在预览和导出中采用同一回退规则；
- 6 款边框均不裁剪照片，支持声明的留白、色纸和投影参数；
- 编辑器和首页均只显示“边框”入口，旧 `template` 输入可兼容打开边框且不再出现空白“模板”面板；
- 草稿和作品续编完整恢复 `EditorSnapshot`；
