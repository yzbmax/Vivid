## 二、导出设置

### 2.1 默认值与页面恢复

- [x] S-01 首次安装或清除应用数据后进入设置页，画质默认选中“标准”。
- [x] S-02 首次进入设置页，格式默认选中“JPEG”。
- [x] S-03 将画质改为“高清”，退出设置页后重新进入，仍显示“高清”。
- [x] S-04 将画质改为“超清”，退出设置页后重新进入，仍显示“超清”。
- [x] S-05 将格式改为“PNG”，退出设置页后重新进入，仍显示“PNG”。
- [x] S-06 选择“高清 + PNG”，完全结束应用进程并重新启动，设置仍然恢复为“高清 + PNG”。
- [x] S-07 切换画质或格式时页面没有明显卡顿、闪烁或选中状态错乱。
- [x] S-08 设置页其他设置项、文字、间距和 Mask & Seal 布局没有异常变化。

### 2.2 六种实际导出组合

每次使用同一张长边大于 2560px 的源图，完成编辑页保存后，在系统相册或文件属性中检查输出。

- [x] E-01 标准 JPEG：输出格式为 JPEG/JPG，最长边不超过 1920px。
- [x] E-02 高清 JPEG：输出格式为 JPEG/JPG，最长边不超过 2560px。
- [x] E-03 超清 JPEG：输出格式为 JPEG/JPG，保持原始尺寸，不主动缩小最长边。
- [x] E-04 标准 PNG：输出格式为 PNG，最长边不超过 1920px。
- [x] E-05 高清 PNG：输出格式为 PNG，最长边不超过 2560px。
- [x] E-06 超清 PNG：输出格式为 PNG，保持原始尺寸，不主动缩小最长边。
- [x] E-07 六种组合均能在系统相册中正常打开，画面没有全黑、花屏、旋转错误或明显裁切。
- [x] E-08 JPEG 三档文件可正常解码；同一源图下高档位没有比低档位更低的输出尺寸。
- [x] E-09 PNG 文件后缀、媒体类型和实际内容一致，不是仅修改后缀的 JPEG 文件。
- [x] E-10 用户取消系统保存操作后，应用不崩溃，也不错误提示“保存成功”。
- [x] E-11 相册写入失败时有明确提示，应用仍可继续使用。
